# T600XFamilyPkg

Apple M1 Pro, Apple M1 Max (T6000, T6001).

Generated by `Tools/add-soc.py` from the device tree for Apple Mac Studio (M1 Max, 2022)
(`Silicon/Apple/AppleSiliconPkg/DeviceTree/`, provenance in `SOURCE.json`), then
owned by hand.

## Status

**UNVERIFIED.** No machine in this family has been booted. Everything below is
what the device tree states.

## What still needs hardware

1. **CSRT / AIC geometry.** IRQ counts and register strides are read off the
   controller at runtime, not declared anywhere. See `AcpiTables/CSRT.aslc`.
   Windows' AIC HAL extension needs it; UEFI does not.
2. **Which core boots.** Assumed UID 0.
3. **Boot-args and ADT pointers.** Placed at the offset both proven families
   use; must be confirmed against m1n1 on this silicon.
4. **The bin.** The core count above is the die. `AcpiPlatformDxe` trims the
   MADT to what the live ADT reports, so a smaller machine is handled, but the
   PPTT is not trimmed.

## What needs nothing

NVMe and the interrupt controller are already generation-agnostic.
`AppleNANDStorageDxe` takes every address from the live ADT (`/arm-io/ans`,
`/arm-io/sart-ans`) and has only two register-map variants, selected from the
ADT. `AppleAicDxe` drives v1, v2 and v3 from one path with the layout read off
the controller.
